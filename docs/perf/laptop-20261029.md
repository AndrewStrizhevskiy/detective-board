Caveats (read before quoting):
- NOT a clean window: `sing-box` (a second VPN), Docker with a media server, the desktop and the assistant app were running. The numbers are an upper bound.
- One day, one machine; no 8 GB profile (not done); series are not independent repeats of the same questions.
- The package temperature stayed at 98-100 C in every series: the CPU is at its thermal limit; throttling is likely in a long demo. Mitigations in `docs/demo/STAGE_CHECKLIST.md` (hard surface or stand, pause between live questions, charger plugged).
- Peak RSS grew from series to series (4991 -> 6289 MB): the second model (bge-m3) and the context caches stay resident (keep_alive 30 min). The 8 GB profile is NOT verified.
