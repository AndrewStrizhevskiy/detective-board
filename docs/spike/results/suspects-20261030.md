# Suspect board before the reveal: results (2026-10-30)

**Fresh held-out result: the best dev method (pairwise tournament, qwen3:14b) names the culprit first in 2 of 6 stories,
the same as ranking by 'most mentioned' (2 of 6); one of its four wrong answers accuses a person the story clears.
The dev result (4 of 8) was optimistic. Nothing here shows that the system finds the culprit.**

Main claim of the project is *does not accuse the innocent*, not *finds the culprit*. Every answer is a `hypothesis`.
All cases are AI-written and AI-marked (culprit, cleared persons, cut, 'solvable'); they need a human check. Samples
are tiny (6, 8 and 8 stories), so every interval is wide.

## 1. Fresh held-out confirmation (6 stories, run once, protocol frozen first)

Protocol: `suspects-prereg-heldout-20261030.md`, committed before the run. Source: Project Gutenberg #204 *The
Innocence of Father Brown* (the user chose this text in the chat before it was downloaded). Stories: The Hammer of God,
The Invisible Man, The Secret Garden, The Eye of Apollo, The Three Tools of Death (accident, no murderer), The Wrong
Shape. Candidates: the project extractor on the pre-cut chunks (graph `data/graph/heldout.sqlite`, 102 chunks).
The three novels the user also approved are NOT used: the text before the reveal (72k to 277k characters) does not fit
the 14,336-token context of the frozen method.

What it shows:
- The tournament picks `NO_PERSON` first in 4 of 6 stories (right once, in the accident story) and never abstains.

  and wrong where the detective Father Brown is the most mentioned name. The candidate list excludes only Holmes and
  Watson, so Father Brown and Flambeau were candidates: a pipeline weakness, not fixed here (frozen protocol).
- Full-context 14B accused cleared persons twice (Joan Stacey, Patrick Royce).

## 3. Dev split (8 stories): exploratory, optimistic

The overnight queue (about 35 variants, `docs/spike/results/suspects-prereg-overnight-20261029.md`) ran on dev only, so
the best dev number is the maximum of many tries and expected to shrink. Selected rows (culprit first / top 3 / abstained /
cleared first / wrong): pairwise 14B 4 / 5 / 0 / 1 / 4 (**best**); pairwise 8B 2 / 4 / 0 / 2 / 6; full-context 14B 3 / 4 /
2 / 2 / 3; full-context 14B with thinking 2 / 4 / 2 / 1 / 4; self-consistency 14B x7 3 / 4 / 0 / 2 / 5; full-context 8B
2 / 3 / 5 / 0 / 1 (seeds vary 1 to 5 abstentions); case-file dossier 8B 1 / 2 / 0 / 3 / 7 (worse than no model);
matrix of cards 3 / 5 / 1 / 0 / 4; most mentioned 3 / 5 / 0 / 0 / 5; bare 2 / 2 / 0 / 1 / 6. The 14B dossier run
timed out after 4 of 8 stories. Longer runs of the same method with other seeds changed the abstention count by up to
four, which is the noise level to keep in mind.

## 4. What can and cannot be said

- Can: with the frozen protocols no tested method reliably beats ranking by how often a name is mentioned; the 14B
  tournament is the only one that also puts the culprit in the top 3 in 5 of 6 held-out stories, as the baselines do.
- Can: methods that abstain on disagreement do not accuse the innocent, at the price of answering almost nothing.
- Cannot: that the system 'guesses the ending'. Cannot: any claim about unseen novels, the cases are 22 short
  stories whose truth and cut points were set by an AI reading the explanations.
- Open: human check of the truth and cut labels; excluding detectives (Father Brown, Flambeau) from the candidates;
  a method that can abstain and still rank (the tournament never abstains); cases from the novels, which need a
  retrieval step because the text before the reveal is longer than the context.
