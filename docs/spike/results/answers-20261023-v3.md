## Caveats

- n=12 questions per model, one run each (temperature 0, seed 42): differences of one question are noise. Per-category cells hold 1-2 questions.
- Key-fact coverage is a crude proxy: share of stemmed content words (3+ letters, stop words removed) of `expected_answer` that occur in the answer text with citations stripped. It rewards paraphrase-free echoes and punishes correct paraphrases and translations (the Russian question: expected answer is Russian, an English answer scores low).
- No human judging of answer correctness: only the 4 answers per model read by hand (notes above) plus the mechanical self-check. `verified` means quotes are verbatim in the sources and lexically support the claim, not that the claim is true.
- Golden set is agent-written and not human-reviewed (eval/golden/README.md).
- Gold overlap uses chunks touching the gold quotes; a correct answer from another chunk or story passage counts as a miss. `cites gold span` is the stricter character-level test.
- Timing is from a CPU-only Ollama (size_vram 0); the first LLM call per model is preceded by a warm-up so load time is not in the per-question numbers. TTFT is end-to-end (routing + retrieval + prefill + first token); total s covers retries.
- The retrieval gate (min_score, min_support) refuses before any LLM call, so its decisions are model independent; thresholds are provisional (backlog R-13).
- Graph and MCP tools are off: alibi/contradiction questions get text retrieval only, so this is not a test of the neuro-symbolic layer.
