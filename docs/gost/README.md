# Комплект программной документации «Детективная доска» (Detective Board)

Комплект документов по ЕСПД (ГОСТ 19.xxx) в формате DOCX на русском языке; рядом лежат PDF-копии для просмотра.
Оформление: ГОСТ 19.106-78, ГОСТ 2.105-95, ГОСТ 7.32-2017 (поля 30/15/20/20 мм, Times New Roman 14 пт, интервал 1,5,
абзацный отступ 1,25 см, нумерация страниц внизу по центру, титульный лист без номера, лист согласования, оглавление,
лист регистрации изменений).

Состояние описываемой системы: ветка `main`, коммит `16122fc` (30.10.2026), версия 0.0.1.
Документы составлены по репозиторию и отчётам в `docs/spike/results/` и `docs/perf/` с помощью ИИ-ассистента,
человеком не проверены и никем не согласованы; подписи, должности, организация и обозначения документов оставлены пустыми.

## Правила комплекта

- Описано только то, что есть в репозитории и что измерено. Каждое число даётся с путём к файлу отчёта.
- Метки статуса: **[Измерено]**, **[Не измерено]**, **[План]**, **[Заполнить]**.
- Угадывание виновного (ветка `feat/suspects-matrix`, её отчёты; ранее `exp/entity-answer` и тест «до раскрытия») описано как исследовательское и ненадёжное: на 6 новых рассказах 2 из 6, как простая базовая;
  ветка `feat/suspects-matrix` в комплект не входит.
- Метки происхождения в системе: `extracted`, `derived`, `conditional` (и `source_text`, `curated`).

## Пересборка

Документы генерируются скриптами `build/` (чистый Python 3, без внешних библиотек; DOCX собирается напрямую в OOXML).

```bash
python3 docs/gost/build/make.py            # все документы
python3 docs/gost/build/make.py d03_op     # один документ
dot -Tpng -Gdpi=170 docs/gost/diagrams/c4_containers.dot -o docs/gost/img/c4_containers.png   # перерисовка диаграммы
```

PDF и номера страниц оглавления получаются через LibreOffice (`~/Applications/LibreOffice.app`) и PDFKit (macOS, `osascript`).
В Word после открытия при расхождении пагинации обновите оглавление: Ctrl+A, F9. Постраничная вёрстка Word может немного отличаться от PDF.
